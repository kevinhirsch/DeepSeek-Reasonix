# Subagent Monitoring UX Patterns Research

**Date:** 2026-06-30
**Source:** Research agent (aaaccb4b972dca323) — 19 web fetch/source operations, 37,336 tokens

## Key Findings

### Claude Code Agent View (Background Tasks Panel)

- **Stack:** React + Ink (React reconciler for terminal)
- **Layout:** Full-screen alternate buffer with session table grouped by state
- **Status icons** (dual-encoding: state + liveness):
  - `✻` animated = Working, process alive
  - `∙` dimmed = Working, process exited (wakes on attach)
  - `⚠` yellow = Needs input
  - `·` dimmed = Idle
  - `✓` green = Completed
  - `✗` red = Failed
  - `○` grey = Stopped
  - `✢` = Sleeping (/loop session)
- **Progressive disclosure:** Row summary (AI-generated by Haiku every ~15s) → Peek panel (Space) → Full attach (Enter)
- **Peek panel:** Shows longest-running parallel item by name and duration
- **Session rows:** Show `done/total` count (e.g., `2/5`) for parallel subagents

### Agent Deck (Go + Bubble Tea reference implementation — 1,951★)

- **Components:** Session list, MCP Manager, Skills Manager, Cost Dashboard, Web UI (Chart.js + SSE)
- **Status state machine:**
  - `●` green = Running
  - `◐` yellow = Waiting
  - `○` gray = Idle
  - `✕` red = Error
- **Key bindings:** Vim-style (j/k, gg, /), Enter to attach, n new session, f quick-fork
- **MCP Socket Pool:** Shares MCP processes across sessions via Unix sockets (85-90% memory reduction)
- **Session persistence:** SQLite

### Alternate Screen vs Inline Viewport Tradeoff

- **No major terminal AI agent uses a pure full-screen TUI** — all write to normal buffer to preserve scrollback
- **Hybrid recommended:** Normal buffer for chat, TUI-managed inline region for input + status bars

### Event Streaming Patterns

- **Event types:** stream.tool_use, stream.tool_completed, stream.subagent.start/end, stream.plan_step_started/completed
- **Concurrent display:** Spinner for active, ✅/❌ for complete, indentation for nesting
- **Auto-removal:** Completed items display for ~2s then disappear
- **Atomic write:** Single `write()` call prevents screen tearing
- **ANSI escape sequence technique:** Clear previous status region → rebuild → atomic write

### Scrolling Buffer Pattern

- `VecDeque<String>` of last N lines
- On new line: pop front if full, push new, redraw atomically
- Truncate to terminal width with ellipsis

### Virtual Terminal Emulation (Critical)

Agent CLIs emit ANSI spinners/progress bars that, when captured raw and stripped of escape codes, leave repeated spinner frames. Solution: embed headless terminal emulator that maintains screen buffer and renders current state as single snapshot.

### Go Bubble Tea Implementation Patterns

- **Elm Architecture:** Model (agents, activeTools, viewport, logLines, statusBar) → Update (message dispatch) → View (lipgloss layout)
- **tea.Batch** for concurrent subagent monitoring (multiple pollAgentStatus + TickMsg)
- **Viewport.SetContent()** + **GoToBottom()** for auto-scrolling
- **Key packages:** bubbletea, bubbles/viewport, lipgloss, bubbles/table, bubbles/spinner
